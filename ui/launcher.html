What is this?
  • This page starts a live view of a model running, and checks every result as it goes. Pick a test, where it runs and which model or build, then press Start.
  • Golden model: an independent Python copy of the exact integer arithmetic the firmware does. Every build has to match it bit for bit; it needs no hardware.
  • PC build: the same plain-C code that runs on the board, compiled for this computer. Pico 2 board: the real firmware, with cycle counts (the times that the results quote).
  • Phase 1 is the MNIST digit model and its compiler; Phase 3 is the tiny story model. "Gate 1" was the goal of beating CMSIS-NN, Arm's standard library, on speed.
  • Flashing goes over SWD (the debug wires of a Raspberry Pi Debug Probe), with picotool over USB as the fallback. Nothing is compiled here: builds come from harness/measure.sh or CMake.

Setup: docs/SETUP.md. Building and measuring: docs/REPRODUCE.md. The pages, panel by panel: docs/UI-GUIDE.md.
